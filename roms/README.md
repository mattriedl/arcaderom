# roms/

Put game files for the free library here, then list each one in `../games.json`.

Only add games you are allowed to redistribute:

- Homebrew games whose author/license explicitly permits redistribution (check the license file or the author's page — "free to download" is not the same as "free to rehost").
- Games you made yourself.

Do **not** put commercial game ROMs here. Visitors who own commercial games can load them with the "Play your own game" box; those files stay in the visitor's browser and never touch your server.

Keep a note of each game's license and source next to it (for example `roms/nes/my-game.LICENSE.txt`).
